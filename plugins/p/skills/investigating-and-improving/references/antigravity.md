# Antigravity transport

Discover the session's available shell, requester interaction, continuation and
delegation capabilities. Use the existing writing-goals Antigravity adapter for
its supported lifecycle; do not transplant another harness's goal command.
Checkpointing makes work resumable, not automatically running.

Run state operations through the Python launcher using the absolute plugin root
derived from this skill. If native background continuation is absent, preserve
pending questions, remaining bounds and next action for the next invocation.
Do not install hooks or change global settings to manufacture continuation.

Route questions through the available requester interface. Continue independent
work only if that interface allows it. Attribute answers to their actual source;
agent-written conversation text is not user preference evidence.

Delegate only if native delegation is exposed and authorized; otherwise execute
branches sequentially. Preserve the parent grant and escalation route in either
case. Record missing enforcement and isolation capabilities explicitly. Corpus
capture support does not establish live agent transport support.

Verify that the shell can write the already authorized private store location;
file-edit tools and terminal tools may have different sandbox permissions. A
denial does not authorize moving outside the assigned scope or restarting the
deadline. Investigate the specific permission boundary, retain completed work,
and report the missing prerequisite if no authorized writable location is exposed.
In print mode, inspect the deadline/turn status and actual acceptance artifacts:
a successful CLI exit can accompany a timed-out, unfinished turn.
