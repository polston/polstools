# Codex transport

Use the tools actually exposed to this session. Where native goal tools are
available, bind the investigation contract to that goal; keep the fixed deadline
and private checkpoint in its objective. Follow the exposed lifecycle semantics.
Do not overwrite a matching active goal or claim saving a checkpoint schedules it.

Use asynchronous requester input when exposed and continue independent work.
Otherwise checkpoint the dependent branch before returning a precise question.
Do not confuse a plan-only input tool with one available during execution.

Native delegated agents can receive bounded briefs when delegation is authorized.
Pass exact inputs, grant, deadline, acceptance and escalation recipient. Keep
confirmation tasks outside candidate context where possible and disclose shared
filesystem access. A separate context alone does not isolate file access.

Run the repository's Python launcher through the available shell tool. Record
actual tool results and artifact references. Shell permission controls are owned
by the host; a ledger grant cannot override them. Token accounting and cancellation
must be marked unavailable or advisory unless the session provides enforcement.

An interrupted turn does not prove its already dispatched tools have stopped.
Inspect outstanding tool receipts and actual effects before retrying or releasing
their reservations. A tested local command continued writing after app-server
acknowledged interruption; its late completion remained in retained turn items.
When an app-server client exposes the documented experimental background-terminal
controls, it can inspect its own thread and terminate an exactly identified owned
terminal. Verify the matching tool's terminal result and effects afterward. A first
empty terminal listing can race registration; it is not a cleanup receipt. These
controls do not establish cancellation of arbitrary external effects or authorize
termination of unrelated work. See the [app-server interface](https://learn.chatgpt.com/docs/app-server).
